# Security

Supported version: 0.1.x. Report a vulnerability using GitHub private vulnerability
reporting if enabled at https://github.com/KanadeK/release-slotcheck/security/advisories/new.
If that channel is unavailable, open an issue asking for a private reporting channel
without including exploit details or sensitive data.

This is a diagnostic tool, not a sandbox or an authenticity verifier. Run on stable
local files. Inputs and reports may contain private paths and product names; review
them before sharing. Do not run untrusted installers or binaries to use this tool.
